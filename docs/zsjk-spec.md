# zsjk 大屏 · 布局改版规格（招商交科 · AI创变营）

> 布局基准：`layout-spec.html`（AI创变营 · 企业黑客松 原型布局 Spec，1920×1080，四页共用骨架）。
> 本规格只描述「做什么、边界、验收标准」；视觉配色/材质不在本规格内。

## 0. 目标与定位

- 新增一套针对「招商交科 · AI创变营」的四页大屏：**首页 / 作战地图 / 岛屿详情 / 人员维度**。
- 布局严格按 layout-spec 的结构与高度预算；**节点与进度口径完全沿用现有 8 节点设计**（需求分析/方案设计/原型设计/代码开发/本地测试/上线部署/线上验收/最终提交，加权 5/5/5/30/15/15/15/10，自报空心环 / 服务端验证实心）。
- **岛院口径（用户已确认）**：岛院 = 数据库「部门」，小组层级在新界面**取消展示**（项目直接挂岛院）。数据层两级结构不动，注册 CLI 不改。
- **承载方式（用户已确认）**：新增路由，旧大屏 `/` 与管理后台 `/admin` 不动；数据共用同一套 `/api/snapshot` + `/api/stream`（SSE）。
- **主标题（用户已确认）**：「招商交科 · AI创变营」。
- **接入卡（用户已确认）**：首页放「skill 引导注册」可复制卡片。
- 其余无真实数据的内容（视频卡、带队讲师、3 天流程等）**保留 mock 占位**。

| 路由 | 页面 | 新文件（web/src/zsjk/） |
|---|---|---|
| `/zsjk` | 首页 | `HomePage.jsx` |

| `/zsjk/people` | 人员维度 | `PeoplePage.jsx` |

共用件（新）：`ZsjkShell.jsx`（pad 骨架 + navpill + ticker 挂载）、`Ticker.jsx`、`model.js`（纯函数聚合）、`zsjk.css`（类名前缀 `zk-`，不改现有 styles.css）。

复用（不改）：`Scale.jsx`（1920×1080 等比缩放）、`useSnapshot.js`（SSE 订阅）、`ProjectDetail.jsx`（岛屿详情弹窗，内容正是 人员/需求/价值/功能/场景 + 打开应用/下载）。

改动（最小）：`main.jsx` 增 4 条 Route；`scripts/gate.js` 增跑 zsjk 单测一条（不改既有套件）。

## 2. 全局骨架（四页共用）

- stage 1920×1080 等比缩放居中，页面零滚动，溢出收敛到容器内部滚动；所有 `flex:1` 区块配 `min-height:0`。
- 内容安全区 1792×1016（pad padding 32/64）：各页内容 940 + ticker 56 + ticker 上边距 20。
- **ticker 事件滚动条**：`[实时动态标签固定] + [视口 flex:1 两端 5% 渐隐 mask]`，内容轨道 gap 44 匀速左移循环；事件文案取快照 `events`（格式与现有 EventFeed 同源口径：时间 + 岛院/项目 + 节点动作）。地图页由「实时同步」开关控制启停，其余三页自动滚动。
- **navpill 迷你页导航**：fixed（不占高度预算），四页互链：首页 / 作战地图 / 岛屿详情 / 人员维度。

## 4. 作战地图 `/zsjk/map`（预算 150+24+488+24+254+20+56 = 1016）

- **p2-title h:150**：水平居中艺术字「作战地图」+ 两侧装饰线；副行「N 座岛院 · M 个立项 · 数据实时同步」；右上角**实时同步开关**（localStorage 持久化，默认开）。
- **islands h:488**：grid 3 列（N 岛自适应行数，行高 232、gap 24）。岛卡纵向：岛名 → `立项数 NN / 进度值 NN%`（mlabel 小标签在数值上方）→ 4px 进度条 → `🔥 人气值 NNN`（岛内项目 hits 合计）。整卡可点 → `/zsjk/island?unit=<deptId>`。
- **charts h:254**：3 等列（echarts 柱状图，柱宽 ≤54、4 条网格线、plot 柱高预算 104，三图同横轴同序=岛院名）：① 立项数 ② 进度值（岛内项目加权进度平均）③ 实时人气值（按项目汇总）。
- **开关行为**：关 → stage 加 `.off`：岛卡与图表整体置灰（灰度+降透明）、岛卡不可点、ticker 停止；开 → 扫光 + 逐卡点亮（CSS 逐卡 animation-delay），进入正常实时刷新。

## 5. 岛屿详情 `/zsjk/island`（预算 88+16+836+20+56 = 1016）

- **p3-top h:88**：左「← 返回作战地图」+ 岛院下拉（「全部岛院（N 座）」+ 各岛院；`?unit=id` 用 replaceState 同步 URL，非法回退 all）；右 3 个统计 pill：项目数 / 平均进度 / 参与人次（按项目 members 汇总）。
- **p3-list h:836**：thead 54 固定（grid `300px 440px 1fr` gap 32：项目名称+编号 / 进度节点 / 项目说明）；tbody flex:1 内部滚动（6px 细滚动条）。
  - 组头：岛院名 + `N 个项目 · 平均进度 NN%`（下拉选中单岛院时只显该组）。
  - 项目行 h:94，整行可点开弹窗：名称+编号（无编号字段，展示合成号 `P-<id>`）｜8 节点 dot 条（done/doing/todo 三态 + verified 实心微光 + 派生样式与现有 ProjectCard 同口径：安装包类型「原型设计」虚线环、部署探活失败标注）+ 加权进度 %｜人员胶囊 + 一句话摘要；第二行 `需求：… · 价值：…`。
- **弹窗**：复用 `ProjectDetail`（遮罩居中，Esc/×/遮罩关闭，人员/需求/价值/功能/场景 + 打开应用↗/下载↓，人气点击口径不变）。
- ticker 全局自动滚动。

## 6. 人员维度 `/zsjk/people`（预算 140+24+776+20+56 = 1016）

- **p4-head h:140**：左标题「人员维度」+ 副行（N 位参与者 · 排序说明 · 点击行查看参与项目）；右 4 张 KPI 卡（min-width 164，自动计算）：榜上人员 / 人均参与 / 平均完成率 / 最高人气。
- **p4-table h:776**：thead 54（grid `420px 200px 1fr 1fr` gap 32，四列均可点排序，升/降切换，默认参与项目数降序）；body 内部滚动，行高 66。
  - 行：头像 42（姓名首字色块）+ 姓名 / 单位·职务（= 所属岛院名，多岛院取首个；职务无数据不显示）｜参与项目数｜完成情况（进度条 + %，参与项目加权进度平均）｜项目人气值（🔥 + 条 + 数值，参与项目 hits 合计）｜展开箭头。
  - 展开区（同时仅一行展开）：参与项目列表——名称+编号+状态 380px → 进度条 flex:1 → Web/桌面 徽标（deliverable）。
- 人员来源：各项目 `members` 字段拆分（分隔符 `、，,;／/` 及空白），trim、去重、滤空。
- ticker 全局自动滚动。

## 7. 数据与口径（不改后端）

- 全部页面消费 `/api/snapshot`（岛院树/项目/KPI/事件）+ `/api/stream` SSE 刷新 + 30s 兜底轮询（`useSnapshot` 现成）。
- 进度值：项目 = 快照 `progress`（加权）；岛院 = 快照部门级 `progress`（与旧大屏同源同值）；图表岛院进度 = 岛内项目 progress 算术平均。
- 人气：项目 `hits`；岛院/人员 = 下辖项目 hits 合计；链接一律走 `/api/hit/go`（计数口径不变）。
- 吊销项目：岛院卡计数含吊销与否？——与旧大屏一致：按快照 deptTree 已有口径（不含已吊销/已归档），不另行加规则。

## 8. 边界（明确不做）

- 不改后端 API、数据库结构、注册 CLI、旧大屏 `/`、管理后台 `/admin`。
- 视频、讲师、流程为静态 mock；一段话简介为占位文案。
- 不做新认证、不做移动端适配（stage 缩放已保证任意视口可见）。
- 岛院数量随当前活动数据自适应（spec 的「6 座岛」仅为基准示例；当前库为 5 部门 → 5 岛）。为演示效果可另建 `data/seed-zsjk.json`（道路院/交规院/景观院/隧交院/管理支撑/技术经营 6 岛示例名单），**仅作为 seed 脚本的可选输入，不自动执行任何写库**。

## 9. 验收标准

1. 四页 1920×1080 下页面级零滚动；各页高度预算逐项等于 spec（170/420/310、150/488/254、88/836、140/776 + ticker 76）。
2. 同一项目在旧屏与 zsjk 屏的进度 %、节点状态完全一致（同一快照字段，无二次换算）。
3. 岛院卡数量 = 当前活动部门数；岛卡点击 → 详情页正确过滤；下拉切换同步 URL；非法参数回退全部。
4. 接入卡一键复制后，剪贴板内容为完整 `--init` 命令（含三个参数占位）。
5. 人员聚合正确：members 拆分/去重的纯函数有单测覆盖（含中英文分隔符、重名合并、空值）；KPI 4 项与表内数据自洽。
6. 实时：SSE 信号后页面刷新；地图开关关闭时置灰且 ticker 停止，状态刷新页面后保持。
7. 旧功能回归全绿：`npm test`（gate：smoke + 三套 E2E + 新增 zsjk 单测）全部通过。
8. 浏览器完整走查四页（含交互：排序/展开/弹窗/复制/开关/下拉），核对布局预算与视觉一致性。
